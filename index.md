\# {lovedial}❤️☎️ ![ Bright yellow hexsticker with a pink phallic phone;
the text 'lovedial' connects to the phone via a curly old-style phone
cord.](reference/figures/logo.png)

Guess who likes you in this secret admirer phone game.

## Installation

Run the following R command to install {lovedial}:

``` r

# install.packages("pak") # if not already installed
pak::pak("statsrhian/lovedial")
```

## Play

``` r

library("lovedial")
new_game()
```
